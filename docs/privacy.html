Kebijakan Privasi

Catatan Keuangan · berlaku sejak 9 November 2026

Catatan Keuangan dibuat agar data keuanganmu tetap milikmu. Pengembang tidak punya server dan tidak menerima, menyimpan, atau melihat datamu. Halaman ini menjelaskan ke mana saja data bisa mengalir dan kenapa.

1. Data yang disimpan di HP

Transaksi, dompet, kategori, dan pengaturan disimpan di penyimpanan lokal HP-mu. API key AI disimpan terenkripsi di HP. Menghapus aplikasi akan menghapus data ini.

2. Login Google

Login dengan Google dipakai untuk mengenali akunmu dan mengaktifkan cadangan ke Google Drive. Aplikasi membaca nama dan alamat email akun Google-mu dan hanya menyimpannya di HP.

3. Cadangan Google Drive

  • Aplikasi meminta izin drive.file: hanya bisa melihat dan mengubah file yang dibuat aplikasi ini sendiri, tidak bisa membaca file lain di Drive-mu.
  • Cadangan disimpan di folder “Cadangan Catatan Keuangan” di Google Drive milikmu, dalam keadaan terenkripsi dengan passphrase yang kamu buat. Tanpa passphrase itu, isinya tidak bisa dibaca — termasuk oleh pengembang.
  • Kamu bisa menghapus cadangan kapan saja dari Google Drive, dan mencabut izin aplikasi di pengaturan akun Google.

4. Fitur AI

Saat kamu memakai fitur AI (mencatat lewat teks/suara, membaca foto struk, insight, atau asisten), aplikasi mengirim data yang diperlukan langsung dari HP ke penyedia AI yang kamu pilih sendiri di Pengaturan, memakai API key milikmu. Data itu bisa berupa teks yang kamu tulis atau ucapkan, foto struk, daftar nama dompet, dan ringkasan transaksi. Pengolahannya tunduk pada kebijakan privasi penyedia tersebut (misalnya Google Gemini, DeepSeek, OpenAI, OpenRouter, atau Groq). Semua fitur lain tetap bisa dipakai tanpa AI.

5. Input suara

Pengenalan suara memakai layanan pengenalan suara bawaan Android di HP-mu. Aplikasi hanya menerima teks hasilnya, tidak menyimpan rekaman suara.

6. Yang tidak dilakukan aplikasi

  • Tidak ada iklan, analitik, atau pelacak.
  • Tidak menjual atau membagikan data ke pihak lain selain yang kamu aktifkan sendiri di atas.
  • Data dari Google API (Google Drive, profil Google) hanya dipakai untuk fitur cadangan dan login, sesuai Google API Services User Data Policy termasuk ketentuan Limited Use.

7. Perubahan dan kontak

Perubahan kebijakan akan diumumkan di halaman ini. Pertanyaan bisa diajukan lewat GitHub Issues.

English summary

Catatan Keuangan has no server; the developer never receives your data. Data stays on your device. Google Sign-In (name, email) is used only to identify your account. Backups use the drive.file scope and are stored, encrypted with your own passphrase, in a “Cadangan Catatan Keuangan” folder in your own Google Drive. AI features send the needed text, receipt photos, wallet names, or transaction summaries directly to the AI provider you choose, using your own API key. No ads, analytics, or trackers. Use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements.
